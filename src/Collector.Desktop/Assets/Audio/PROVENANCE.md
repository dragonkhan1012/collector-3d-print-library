# «Лунный архив» / Moonlit Archive

Дата создания: 15 октября 2026 года. Создано специально для проекта «Коллекционер».

Оригинальная процедурная инструментальная композиция: мягкие синтезированные колокольчики и протяжённые гармонии. Продолжительность 96 секунд. Файл WAV, stereo PCM 16 bit, 22050 Hz. Уровень намеренно снижен для фонового прослушивания.

Вся фонограмма синтезирована математически скриптом `tools/compose_music.py`. Скрипт содержит последовательность нот, гармонию, тембры, огибающие и эхо; использует только стандартную библиотеку Python. Не использовались чужие фонограммы, сэмплы, вокал, музыкальные библиотеки или конкретный существующий саундтрек в качестве образца. Мелодия и скрипт созданы при помощи ИИ в рамках разработки проекта.

## Звуки интерфейса

`ui-hover.wav` (130 мс) и `ui-click.wav` (200 мс) — оригинальные синтезированные звуки наведения и нажатия. Созданы математически скриптом `tools/compose_ui_sounds.py`, без внешних сэмплов и записей.
